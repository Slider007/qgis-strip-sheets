# Листы вдоль трассы

Модуль QGIS (меню «Модули → Альтан-Эко», панель «Альтан-Эко»): линейный объект → листы заданного формата
и масштаба с рамкой ГОСТ → атлас и один PDF.

1. Выделите трассу на линейном слое. Слой в МСК или UTM; трасса в градусах (KML, GPX) пересчитывается
   в систему координат проекта, если та метрическая.
2. Нажмите «Листы вдоль трассы», выберите формат (А4…А0, кратность: А3×3 = 891×420 мм), масштаб,
   поворот (по трассе или север вверх), перекрытие.
3. Географическая сетка ставится круглым шагом под масштаб (1:2000 — 10″ по долготе, 5″ по широте).
   Видимые сейчас слои и их стили запоминаются темой оформления «<название> от <дата>»
   (без названия — «Тема оформления 1»; если тема занята другим альбомом — следующий номер), по ней рисуются карты альбома.
   Заполните штамп (хранится в проекте) и нажмите «Разбить на листы»: появится слой «Листы — <трасса>»
   и макет-атлас с тем же именем. Первый лист — рамка по форме 3, остальные — по форме 6.
   Если альбом этой трассы уже есть, модуль спросит, собрать ли его заново: ручные правки в макете пропадут,
   штамп сохранится (поменять только штамп — «Обновить штамп»).
4. «Сохранить PDF…» выводит все листы одним файлом; разрешение — 150 точек на дюйм (можно 100…300),
   подложка сжимается, чтобы файл был лёгким.
5. Готовые альбомы проекта — в блоке «Готовый альбом»: открыть макет (атлас уже включён), обновить штамп
   (листы и ручные правки макета не меняются), вывести PDF. Если проект сохранён, листы пишутся в
   `<проект>_листы.gpkg` рядом с ним и альбом переживает закрытие QGIS.

Тот же расчёт листов есть в панели инструментов анализа: «Листы вдоль трассы».
