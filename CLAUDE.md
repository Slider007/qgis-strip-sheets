# Модуль QGIS «Листы вдоль трассы» (strip_sheets)

Общие правила — навык `qgis-plugin`. Устройство для пользователя — `README.md`.

## Выпуски

- 1.0.0 — 2026-10-25, первый выпуск (репозиторий `Slider007/qgis-strip-sheets`, раздача через altan.pro).

## Как выпускать версию

1. `tests/run_tests.sh` на 4.x, 3.44 и 3.40 (`QGIS_APP=…`) — все проверки проходят.
2. Поднять `version=` и дописать `changelog=` в `strip_sheets/metadata.txt`.
3. После «да» — `git init` (репозитория пока нет), коммит от Slider007, `Slider007/qgis-strip-sheets`,
   `gh release create vX.Y.Z "$(./build_zip.sh)"`, раздача через `altan.pro` — отдельное «да».

## Устройство

- `core.py` — форматы ГОСТ 2.301 (`page_size`, `map_size`: поле карты = лист минус 20/5 мм) и `split_line`:
  от начала линии ищется двоичным поиском самый дальний конец участка, который помещается в лист за вычетом
  отступов (`PAD_X` 15 мм, `PAD_Y` 60 мм — ниже штамп формы 3 высотой 55 мм); лист повёрнут по хорде участка,
  угол приводится к −90…90°, чтобы север не смотрел вниз.
- `processing/sheets_algorithm.py` — `stripsheets:sheets`: поля `sheet`, `angle`, `from_m`, `to_m`. Линии сливаются
  `collectGeometry(...).mergeLines()` (только стыкующиеся концами); трасса в градусах пересчитывается в СК проекта
  (`context.project()`), если та метрическая, иначе понятный отказ.
- `layout.py` — один макет из двух шаблонов: `forma_3.qpt` (ГОСТ Рамки, «шир.рамки», пользователь прислал
  2026-10-24) + элементы `forma_6.qpt` («динамические рамки 01/формы/forma_6_Альтан»). Каждой форме — свой
  показ по `@atlas_featurenumber` (ExcludeFromExports + прозрачность для окна макета). Рамки динамические
  (позиции от `@layout_pagewidth/height`), переменная макета `layout_tip`=0 (2 строки согласования, 1 — 3).
  Карты обеих форм — атлас, фиксированный масштаб, поворот из поля `angle`.
- `layout.update_stamp` переписывает только надписи штампа в готовом макете; `layout.albums` — макеты с меткой
  `strip_sheets`; `layout.save_sheets` — листы в `<проект>_листы.gpkg` (проект не сохранён — временный слой).
- `plugin.designer_opened` (сигнал `iface.layoutDesignerOpened`) включает просмотр атласа в макетах модуля.
- `export_pdf`: 150 dpi по умолчанию, без lossless (растр — JPEG), `simplifyGeometries`.
- `forma_6.qpt`: добавлены 7 надписей `*-верх` — копии ячеек 14–19 и «сетка-3» на 10 мм выше: две строки
  изменений над «Изм.», вровень с графой заказчика (пользователь, 2026-10-25: «слева обрывается»).
- Сетка: у географических сеток шаблонов (EPSG:4326) шаг ставит `core.grid_step` — самый мелкий из круглых
  шагов `GRID_STEPS` (1″…1°), при котором линии на бумаге не ближе 5 см; долгота и широта отдельно.
  Подписи: долгота сверху/снизу, широта слева/справа (на повёрнутых листах иначе слипаются).
- `layout.make_theme(project, name, album)` — тема карты из текущей видимости слоёв «<название> от ДД.ММ.ГГГГ»
  (пусто — «Тема оформления N»). Свою тему альбом перезаписывает; тему, по которой рисуется другой альбом, —
  нет: берётся следующий номер. Карты альбома следуют теме.
- Перекрытие: следующий лист сдвигается минимум на ¾ охвата (`core.split_line`). `from_m`/`to_m` — сквозной счёт
  через все линии. `save_sheets` → `(слой, '')`, `(None, '')` — проект не сохранён, `(None, путь)` — запись не вышла.
- Пересборка готового альбома — только после вопроса `rebuild_box` («Собрать заново» / «Отмена»); имя, занятое чужим
  макетом, получает номер: «Листы — X (2)».
- Штамп пишется в проект при каждом изменении поля (`textChanged`), при показе окна перечитывается из проекта.
- `dialog.py` — окно; штамп — `QgsProject.writeEntry("strip_sheets", …)`, остальное — `QgsSettings`.

## Решения пользователя (2026-10-24/25)

- Задаются масштаб и формат, число листов считает модуль. Поворот листов — выбор в окне.
- Рамки — свои шаблоны пользователя (форма 3 первый лист, форма 6 последующие). В модуль положены копии
  без фамилий и названий объектов (репозиторий публичный).
- Имя — «Листы вдоль трассы», папка `strip_sheets`.
- PDF как можно легче: 150 dpi и меньше. Готовый альбом должен правиться (штамп) и открываться с включённым атласом.
- Сетка — круглым шагом по масштабу (2026-10-25); в шаблонах было 0,01° и 0,04°.
- Тема оформления при каждой разбивке: название из окна, иначе «Тема оформления 1», плюс дата (2026-10-25).
- Ставить для проверки в QGIS 4 (`QGIS4/profiles/Profil_QGIS-4`, ссылка на папку модуля).

## Грабли

- **Не вызывать `layout.initializeDefaults()` перед `loadFromTemplate`.** Страница по умолчанию оставалась в сцене до
  отложенного удаления; если оно срабатывало посреди вывода (подложка из плиток — QGIS ждёт их и обрабатывает события),
  QGIS падал в `QGraphicsScene::drawItems` на 3.40, 3.44 и 4.2.3. Воспроизводится только медленными плитками: в кэше
  они берутся мгновенно, и падение «плавает». Стенд — свой медленный сервер XYZ (сервер OSM гонять нельзя), адрес
  плиток каждый раз новый, чтобы не брать кэш `~/Library/Caches/data8` (общий для всех сборок без профиля).
  Тест держит одну страницу в сцене. Две стрелки севера к падению отношения не имели (проверено тем же стендом).
- **В шаблонах легенды хранили дерево слоёв старых проектов** — с названиями объектов заказчиков и путями к файлам.
  Из `forma_3.qpt`/`forma_6.qpt` дерево вычищено (`<layer-tree-group/>`), легенду модуль собирает из слоёв проекта
  (без листов и растров), фильтр по карте листа остаётся. Новый шаблон — проверять на `name=`, `source=` и подписи.
- Стрелка севера из формы 3 стоит в правом верхнем углу поля карты: на прежнем месте её закрывала легенда формы 6.
- Кнопка «Закрыть» подписана явно: без перевода Qt (снимки, тесты) она «Close».
- `tests/ui_shots.py` падает при выходе (вопрос «Собрать заново» удаляется после родителя) — это стенд, не модуль.
- `loadFromTemplate` возвращает и страницу: если спрятать её по номеру листа, PDF выйдет в одну страницу.
- Карта после загрузки шаблона оказывается под фоном страницы, если ставить ей `setZValue(-1)`: опускать через
  `layout.moveItemToBottom`.
- Путь SVG стрелки севера в коде — через `QgsSymbolLayerUtils.svgSymbolNameToPath`, относительный не находится.
- `QgsLayoutRenderContext.Flag` в 3.40 нет: там `FlagLosslessImageRendering`, в 3.44+ — `Qgis.LayoutRenderFlag`.
- `layout.items()` отдаёт и служебные `QGraphicsRectItem` без `id()`: фильтровать по типу.
- PDF с растром весит много даже при 150 dpi, если подложка шумная (тест на шуме: ~30–45 МБ на 4 листа А3×3).
- `QgsGeometry.unaryUnion` режет линию в точках самопересечения (петля → 3 куска в произвольном порядке):
  для трассы не использовать (находка 1 проверки 25.10).
- В тестах провайдер держать в переменной и не удалять из реестра между тестами (удалённый не вернуть).
